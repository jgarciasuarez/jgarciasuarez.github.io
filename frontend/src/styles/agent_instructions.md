# Styles & Design System Agent Instructions

## Directives
1. **Design Concept**: Professional, slick, dark-themed academic portfolio. It must look premium and modern.
2. **CSS Variables**: All design tokens (colors, fonts, spacing) must be defined as CSS variables in a global CSS file (e.g., `globals.css` or `theme.css` in this folder).
3. **Colors**: 
   - Backgrounds should be deep, rich dark colors (e.g., very dark slate or near-black).
   - Accents should be vibrant but professional (e.g., neon blue, teal, or amber) used sparingly for interactive elements and borders.
4. **Typography**: Use modern fonts like Inter, Roboto, or Outfit. Define a clear typographic scale for `h1` through `h6`, and standard `p` text.
5. **Effects**: Utilize modern CSS effects like `backdrop-filter: blur()` for glassmorphism and subtle CSS gradients for backgrounds or text clips.
