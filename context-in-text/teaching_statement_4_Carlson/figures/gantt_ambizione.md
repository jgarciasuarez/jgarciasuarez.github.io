# gantt_ambizione.png Description

This image is a timeline diagram titled "Project Gantt Chart", illustrating the schedule of various work packages (WP) over a 48-month duration. The x-axis is marked in 6-month intervals (0, 6, 12, 18, 24, 30, 36, 42, 48).

The chart contains three rows, each corresponding to a different group of work packages:
- **Top Row (Blue):** Shows sequential, non-overlapping tasks.
  - WP1.1 spans months 0 to 12.
  - WP1.2 spans months 12 to 18.
  - WP1.3 spans months 18 to 24.
  - WP1.4 spans months 24 to 33.
  - WP1.5 spans months 33 to 48.
- **Middle Row (Red):** Shows overlapping tasks representing a second track of work.
  - WP2.1 spans months 0 to 18.
  - WP2.2 spans months 18 to 33.
  - WP2.3 spans months 33 to 48.
- **Bottom Row (Orange):** Shows the longest continuous tasks.
  - WP3.1 spans months 0 to 18.
  - WP3.2 spans months 18 to 48.
